1

Discover

Agent advertises _localmesh._tcp (mDNS). TXT carries aid, display name, and an SPKI-pin hint (untrusted; TLS verifies the real pin).

2

Pair

App scans the Agent QR (one-time Pairing Secret). Owner approves on the PC (admin console). Trust binding FR-PAIR-03.

3

Trust

TLS 1.3-only with SPKI pinning. App generates a P-256 device key inside the Android Keystore; Agent issues an opaque Device Token.

4

Connect

SM-CONN runs the §16.1 staggered race across endpoints (LAN first, Tailnet next); token refresh is scheduled at 80% of lifetime.

5

Stream

Chat runs over SSE (SM-STREAM): unnamed chunks + mesh.meta / mesh.stats / mesh.error frames; cancellation and revocation handled mid-stream.

Every step is stateless-safe: any failure lands in the §18.3 reason ladder (UNREACHABLE, PIN_MISMATCH, REVOKED, BLOCKED_PERMISSION, ...) and the Doctor walks the same ladder top-down to explain it.
